# 방 효과 (셰이더 팩) 시험

방 엔진 위에 화면 효과를 얹어 보는 시험이다. 마인크래프트의 셰이더 팩처럼 블록은 그대로 두고 그리는 방식만 바꾼다.
지금은 `?debug=1` 로 연 방에서만 켜진다. 디버그가 아니면 엔진이 예전처럼 `renderer.render` 를 바로 부르고, 효과 코드는 받지도 않는다.

## 쓰는 법

1. 방 주소에 `?debug=1` 을 붙인다. 예: `/room/lovesoo?debug=1`
2. 오른쪽 `디버그` 탭 → `방 효과`. 묶음마다 켜고 끄고, `값` 을 누르면 슬라이더가 나온다.
3. 값은 이 브라우저의 localStorage(`heap-fx`)에 남는다. `효과 기본값으로` 로 되돌린다.

처음 켜면 AO, 부드러운 그림자, 환경광, 블룸이 켜져 있다. 피사계 심도, 색 보정, 그레인·비네트는 꺼져 있다.

## 체인

장면(선형 HDR, MSAA 4) → AO(GTAO) → 블룸 → 피사계 심도 → 톤 매핑·sRGB → 배경 깔기 → 색 보정·비네트·그레인

- 부드러운 그림자(PCSS)와 환경광(IBL)은 패스가 아니라 재질과 조명을 바꾼다. 둘만 켜면 체인 없이 그린다.
- 파일: `engine/fx-flags.js`(값과 슬라이더 표), `engine/fx.js`(체인), `engine/fx-probe.js`(측정, 개발 전용), `heap-room.tsx` 의 `FxDebug`.

체인을 거치면 그림이 조금 달라진다. 효과를 하나도 켜지 않은 체인과 지금 그림을 비교해 맞춘 것:

| 차이 | 원인 | 처리 |
|---|---|---|
| 배경 하늘색이 바뀜 (ΔE 4~6) | three 는 sRGB 배경을 톤 매핑하지 않는데, OutputPass 는 모두 톤 매핑한다 | 장면을 투명하게 그리고 톤 매핑 뒤에 배경을 깐다. 하늘 차이 0 |
| 땅 가장자리 고리 | 알파가 곱해진 색을 톤 매핑함 | 톤 매핑 전에 알파로 나눈다 |
| 블룸이 하늘을 어둡게 섞음 | 블룸이 알파까지 더함 | 블룸은 색만 더한다 |
| 빛줄기가 회색 판처럼 보임 | 더하기 섞기가 선형 공간에서 일어나 어두운 곳이 훨씬 밝아짐 | 체인일 때 불투명도 × 0.4 (9·15·18시에 차이가 가장 작은 값) |

남은 차이: 평균 ΔE 0.42, 방 화소의 4.6% 가 2.3 을 넘는다. 대부분 물체 가장자리(선형 공간의 안티에일리어싱)와 반짝임이다.

## 기본값과 근거

출발점은 엔진 기본값과 연구 값이다. 그 뒤 측정 목표를 먼저 정하고 값을 골랐다. 모든 최종 값은 결과를 본 뒤 정한 사후 조정이다.
측정: 러브쑤 방, 1440×900, 15시와 21시 고정, 프레임 루프를 멈추고 같은 장면을 설정마다 그린다. 같은 설정을 두 번 그리면 차이 0.

| 효과 | 기본값 | 출발점(출처) | 정한 목표 | 결과 (15시 / 21시) |
|---|---|---|---|---|
| AO | 세기 0.5, 반경 0.5 m, 해상도 ½ | URP GTAO 0.4·0.3 m, Godot 1.0 m, three 예제 | 구석 ΔL* −3~−8, 트인 바닥 ±0.5, 검정 뭉개짐 +0.5%p 이하 | 구석 −3.7 / −2.8, 바닥 0, 뭉개짐 −0.05 / −1.15 (환경광과 함께) |
| 부드러운 그림자 | 광원 2°, 표본 16 | NVIDIA PCSS 16+16, 1 m 물체 그림자 몇 cm | 가까운 가장자리는 그대로, 먼 가장자리만 넓게 | 가장자리 p10/p50/p90: 지금 1.1/2.6/4.2 cm → 0.9/5.1/21.2 cm |
| 환경광 | 세기 0.6, 반구광 0.2 남김 | IBL 을 켜면 반구광을 줄인다(겹침 방지) | 평균 L* ±1, 뭉개짐 +0.2%p 이하, 반구광 가장 적게 | 9·15·18·21시 모두 ±0.25 |
| 블룸 | 세기 0.2, 퍼짐 0.5, 문턱 1.0 | Godot 문턱 1.0, 세기 0.2~0.4 가 "은은함" | 밤에 방의 5% 이하만 밝아짐 (우리가 정한 값, 출처 없음) | 낮 0.1%, 밤 4.3% |
| 피사계 심도 | 꺼짐, 조리개 0.001 | Held 외 2010: 깊이를 따르는 흐림이 작은 모형처럼 보이게 한다 | 사진 더미는 선명해야 함 | 조리개 0.003 이면 더미 선명도 45%, 0.001 이면 69%. 다음(디오라마) 결정과 함께 |
| 색 보정 | 꺼짐 (따뜻함 +400K, 검정 L* 8, 채도 0.9, 대비 0.95) | 출처 없음. 취향 값 | 아직 측정하지 않음 | — |
| 그레인·비네트 | 꺼짐 (모서리 −0.6 EV, 그레인 0.03) | 30° 화각의 cos⁴ 감광 ≈ 0.75 EV, 그레인 σ 1~2% | 아직 측정하지 않음 | — |

판정 기준: CIE 1976 ΔE 2.3 을 겨우 보이는 차이로 쓴다. 선명도(라플라시안 분산)는 대비에도 반응하므로 흐림의 위쪽 한계로만 읽는다.

환경광은 시간대를 따른다. 한 번 구운 환경 지도는 밤에도 낮만큼 밝아서(21시 평균 L* +9) 세기를 그 시각의 반구광에 비례시키고, 반구광 색이 바뀌면 다시 굽는다.

## 비용

이 PC(1440×900, 화소 비율 1)에서 한 장에 걸린 시간(60장 중앙값):

| | ms |
|---|---|
| 지금 | 5.1~5.9 |
| 체인만 | 6.1~7.9 |
| AO | 10.1 |
| 부드러운 그림자 | 5.3 |
| 환경광 | 5.6 |
| 블룸 | 7.0 |

휴대폰은 재지 않았다. 화소 비율 2 인 화면은 AO 와 블룸 비용이 약 4배다.

## 아는 한계

- AO 는 직사광까지 어둡게 한다(three GTAO 의 방식). 환경광 없이 AO 만 켜면 검정이 뭉개진다(+0.7~2%p).
- AO 가 창, 찬장, 냉장고 둘레 벽을 넓게 어둡게 한다(헤일로). 반경을 줄이면 줄지만 구석 그늘도 약해진다.
- 21시 구석 그늘은 −2.8 로 목표(−3)에 조금 못 미친다.
- 환경광을 켜면 사진 더미의 대비가 내려간다(선명도 지표 0.87). 흐려진 것이 아니다.
- Windows(ANGLE)에서 PCSS 셰이더가 "초기화되지 않았을 수 있는 변수" 경고를 낸다. 그림에는 영향이 없다.
- 측정은 러브쑤 방 하나다.

## 측정 다시 하기

`?debug=1` 로 연 방의 콘솔에서:

```js
const canvas = document.querySelector('canvas');
const probe = (configs, opts = {}) => new Promise(res => canvas.dispatchEvent(new CustomEvent('heap:dev', { bubbles: true, detail: { cmd: 'fxprobe', configs, ...opts, cb: res } })));
await probe([{ name: 'AO', set: { ao: { on: true } } }], { hour: 15 });
```

맨 앞 세 줄(모두 끔, 같은 설정 다시, 체인만)은 자동으로 들어간다. `set` 은 켤 묶음과 바꿀 값, `force: true` 는 효과 없이 체인으로, `heat: 'base' | 'pipe'` 는 ΔE 열지도, `png: true` 는 그린 그림을 돌려준다.
