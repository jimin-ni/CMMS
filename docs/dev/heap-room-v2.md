# 방 v2: 고정 소품을 가구로

브랜치 `yoon-claude/heap-room-v2`. 러브쑤 시안 2 를 모든 방의 기준으로 삼고, 방에 붙박여 있던 소품을 가구 목록(`layout.items`)으로 옮긴다.

## 원칙

- 꼭 있어야 하는 것은 문(`layout.door`) 하나다. 나머지는 모두 꾸미는 사람이 넣고 빼고 옮기는 가구다. 방문자가 아무것도 할 수 없는 방도 허용한다.
- 예외: 온보딩 방(`lovesoo`, `src/components/onboarding-c/story.ts` 의 `ONBOARDING_ROOM_ID`)에는 사진 더미가 늘 있어야 한다.
- 벽 높이는 2.5 가 기본이자 최소다 (`HEAP_POLICY.layoutWallHMin`). 땅 색은 모든 방이 `HEAP_POLICY.groundColour` 를 같이 쓴다 (`layout.ground` 가 있으면 그 방만 그 색).

## 없어지는 최상위 필드

`layout.table`, `layout.screen`, `layout.guestbook`, `layout.posters`, `layout.window`. 저장 검사(`validateLayout`)는 이 필드를 더 받지 않는다. 기존 방과 템플릿은 아래 가구로 바꿔 저장한다 (백업 후 한 트랜잭션).

## 새 손 가구 (`type`)

모든 좌표는 다른 가구와 같다: `x`, `z`, `rot`(90 단위), 다른 가구 위에 올리면 `y`(받침 윗면 높이).

| type | 놓는 곳 | 바닥 크기 w x d | 받침 윗면 | 필드 | 하는 일 |
|---|---|---|---|---|---|
| `heap` | 바닥, 가구 위 | 1.2 x 0.9 | 없음 | `style: "box"`(신발상자, 없으면 흩어진 더미) | 사진 더미. 방에 하나까지. 누르면 옆에 서서 더미를 본다 |
| `lowTable` | 바닥 | 2.6 x 1.8 | 0.56 | `rug: { w, d }`(1..6, 없으면 3.8 x 2.9) | 좌식 탁자 + 러그 + 앞의 방석 + 머그. 이 위의 더미는 방석에 앉아 본다 |
| `phone` | 가구 위, 바닥 | 0.2 x 0.35 | 없음 | | 누르면 그 자리에서 휴대폰 화면(버블 링크)을 연다 |
| `guestbook` | 가구 위, 바닥 | 0.5 x 0.36 | 없음 | `style: "stand"`(나무 받침째, 바닥에) | 방명록 공책. 누르면 그 자리에서 방명록을 연다 |
| `screen` | 벽 | 1.74 x 1.04 (틀 포함 폭 x 높이) | | `y`(가운데 높이) | 벽 스크린. 지금은 장식이다 |
| `poster` | 벽 | 0.74 x 1.2 (틀 포함 폭 x 높이) | | `y`(가운데 높이) | 가장 많이 본 쇼츠를 거는 포스터. 목록 순서대로 1, 2, 3 위 |
| `window` | 벽 | `w` | | `y`, `w`(0.3..3), `h`(0.3..2) | 창. 벽에 구멍을 내고 햇빛이 든다. 첫 창이 해의 방향을 정한다 |

벽 가구는 액자(`frame`)와 같은 자리 규칙을 쓴다: 뒷벽이면 `z = -d/2`, `rot 0`, 왼쪽 벽이면 `x = -w/2`, `rot 90`, 모서리에서 `frameWallMargin` 안쪽. 높이 `y` 는 액자와 달리 고를 수 있다: 가구 위아래 끝(틀 포함)이 바닥 위 0.3 과 벽 윗선 0.08 아래 사이에 든다.

`tableRound`(카탈로그 모델, 0.73 높이 받침 하나의 원탁)가 카페 탁자다. 그 위의 더미는 서서 본다.

## 영사기

이번에 걷어 낸다. 집어 든 사진을 크게 본 화면(카드 보기)에서 두 번 누르면 공식 플레이어로 영상이 열린다.

## 꾸미기

- 메뉴에 위 가구가 모두 있다. 사진 더미는 메뉴에서 일반 폴라로이드 그림으로 보이고, 방에 놓였을 때만 더미나 상자 모양이다.
- 방에 더미가 있으면 메뉴의 더미는 놓을 수 없다 (쪽지 트리와 같다). 온보딩 방에서는 더미를 뺄 수 없다.
- 더미, 창의 자리가 바뀌면 방을 다시 마운트한다 (벽 구멍과 더미 자리는 마운트 때 정해진다).
