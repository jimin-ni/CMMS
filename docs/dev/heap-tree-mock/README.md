# 힙 쪽지 트리 목업 (인계용)

크리에이터 방에 놓는 트리 목업입니다. 팬이 쪽지를 달고, 방문자는 쪽지를 집어 읽은 뒤 다시 걸어 둡니다. 앱 코드(`src/`)와 DB에는 연결되어 있지 않은 단독 HTML 목업입니다. 장식 작업은 이 버전(v1.2)부터 이어서 진행하면 됩니다.

## 실행

GLB를 불러오기 때문에 파일을 바로 열면 안 되고, 정적 서버로 띄워야 합니다.

```bash
py -m http.server 3902 --bind 127.0.0.1 -d docs/dev/heap-tree-mock
```

- `http://127.0.0.1:3902/`: v1.2 (장식 + 쪽지)
- `http://127.0.0.1:3902/v1.1.html`: v1.1 (쪽지만)
- `http://127.0.0.1:3902/?scale=1`: 크기 비교 줄 (장식 8종, 닫힌 쪽지, Kenney 방울 1개)
- `share/tree-compare.html`: v0부터 v1.1까지 비교 페이지. 서버 없이 바로 열립니다.

three.js(`three@0.160.0`, 앱과 같은 버전)와 손글씨 글꼴은 CDN에서 불러오므로 인터넷 연결이 필요합니다. 쪽지 내용과 이름은 모두 예시 데이터입니다.

## 정해진 것 (Yoon)

- 시점은 고정입니다. 회전과 확대는 없습니다. 쪽지를 집어 내 쪽으로 가져와 읽고, 원래 자리에 다시 걸어 둡니다.
- 쪽지는 교실 띠 매듭 접기입니다.
  - 접는 순서: 종이를 세로로 두 번 접어 띠를 만듭니다. 왼쪽 끝을 45°로 꺾어 짧은 꼬리를 내립니다. 오른쪽을 내려 두 꼬리를 나란히 붙입니다. 긴 끝을 짧은 꼬리 밑으로 끼워 넣습니다.
  - 완성 모양: 오른쪽 위에 마름모 머리가 있고, 왼쪽과 아래로 꼬리가 하나씩 직각으로 나옵니다.
- 펼치기는 네 박자입니다. 한 박자에 한 접는 선만 돌고, 종이는 항상 화면 가운데에 있고, 글이 쓰인 면은 보는 사람 쪽을 향합니다.
- 글씨 크기는 길이에 따라 바뀌고, 최소 크기는 지킵니다. 줄바꿈은 지키고, 손글씨 글꼴은 쓴 사람마다 하나로 고정합니다.
- 크리에이터 답장은 두 번째 종이로 쪽지 안에 함께 접혀 있습니다. 답장은 모두에게 공개됩니다.
- 장식은 저해상도로 만들고, 트리 크기에 맞추고, 색을 바꿀 수 있어야 합니다. 거슬리지 않고 예쁘고 귀여워야 합니다.
- 결정할 것: 모양이 다른 쪽지들 자체를 장식으로 쓸지, 장식 안에 쪽지를 넣을지. 트리 전체 모습을 보고 정합니다.
- 트리는 지금 Kenney 장식 트리를 그대로 씁니다. 트리 모양 작업은 나중에 합니다.

## v1.2 현황

- 장식 8종: 방울, 종, 별, 하트, 선물상자, 장갑, 눈꽃, 사탕. 코드로 만든 평면 음영 무광 도형이고 텍스처는 없습니다.
- 크기: Kenney 방울은 트리 1.8 m 기준으로 0.140 × 0.140 × 0.121 m입니다. 우리 장식은 종류와 상관없이 가장 넓은 폭이 0.11 m로, Kenney 방울의 약 79%입니다.
- 열기:
  1. 화면 가운데로 날아옵니다.
  2. 장식이 열립니다. 방울, 하트, 사탕은 반으로 갈라지고, 종은 기울고, 선물상자는 뚜껑이 열리고, 장갑은 손목이 벌어집니다. 별과 눈꽃은 앞뒤로 갈라집니다.
  3. 쪽지가 올라오고, 껍데기는 흐려지며 아래로 내려갑니다.
  4. 쪽지가 펼쳐집니다.
- 닫기는 같은 순서를 거꾸로 밟아 원래 자리로 돌아갑니다. 위치 오차는 0입니다. Esc를 누르면 어느 단계에서든 되돌아가고, 두 개를 동시에 열 수는 없습니다.
- 색 패널(목업 전용): 종류 칩, 색을 바꿀 대상, 색 8가지와 자유 색, 포인트 색(금/은/크림)이 있습니다.

## 트리 꾸미기 수정 (Jimin, `index.html`)

위 v1.2 현황 중 장식 종류, 크기, 색, 거는 방식은 아래 내용으로 바뀌었습니다. 원본 GLB는 고치지 않고, 불러온 뒤 `trimTree()`에서 처리합니다.

- 트리: Kenney에 들어 있던 방울 7개와 꼭대기 보라 별을 뺐습니다. 띠 3개는 지우고, 그 중심선을 따라 구슬 줄 3세트(9줄)를 다시 만듭니다.
  - 세트 색은 베이지, 노랑, 갈색빛 빨강입니다. 줄마다 45° 단위로 돌려 기울어진 방향이 서로 다릅니다.
  - 구슬은 평면 음영 20면체이고, 지름은 5~7.5 mm입니다. 줄마다 크기가 다르고, 한 줄 안에서도 ±15% 차이가 납니다.
  - 구슬은 하나씩 잎 표면에 붙입니다. 구슬 수는 세트별로 5%, 7%, 10% 줄였습니다.
- 꼭대기 별: 각진 노란 별이 스스로 빛납니다. 깜빡이지 않고, 뒤의 햇살 빛줄기만 천천히 돕니다.
- 불빛 줄 6개: 흰색(`#EAE5D9`) 3줄과 금색(`#CDAB3D`) 3줄이 번갈아 있고, 각자 6~17° 기울어져 있습니다.
  - 전선은 갈색이고, 가지 8곳에 걸려 사이가 살짝 처집니다.
  - 전구마다 2.4~4초 주기로 서서히 켜졌다 꺼집니다. 빛 번짐은 넓게 퍼지고 가장자리는 거의 투명합니다.
- 조명: 노을 지는 저녁으로 바꿨습니다. 방보다 밝은 것(전구, 별)에만 빛 번짐(bloom)이 걸립니다.
  - 쪽지를 열면 번짐을 줄이고, 종이 자체 밝기를 올려 읽기 쉽게 했습니다.
- 장식:
  - 종류는 방울, 선물상자, 장갑 3가지이고, 색은 베리, 크림, 머스터드, 클레이 4가지입니다.
  - 크기는 v1.2의 80%(가장 넓은 폭 0.088 m)입니다. 다른 종류의 코드는 지웠고, 필요하면 git 이력에서 찾을 수 있습니다.
- 거는 방식: 모든 장식이 짧은 끈으로 바로 위 가지에 걸립니다.
  - 장식은 그 자리 잎 경사의 1.5배만큼 뒤로 기대고, 뒷면은 잎에 묻히지 않습니다.
  - 쪽지(장식) 수는 24개에서 14개로 줄였습니다. 정면 ±60° 안에서, 맨 아래 층보다 위에만 겁니다.

## 남은 약점

- 장식이 화면에 너무 크게 옵니다. 화면의 약 40%를 차지해서, 열린 껍데기가 화면을 가립니다.
- 흐려진 껍데기가 펼친 종이 아래로 보입니다.
- `?scale=1` 크기 비교 줄이 트리 아래쪽과 겹칩니다.
- 선물상자 뚜껑 안쪽이 밋밋한 판으로 보입니다.
- Codex 리뷰(P2): 쪽지가 열린 동안 흐려진 껍데기가 클릭을 받아, 누르면 아무 일도 일어나지 않습니다. 장식의 모든 부분이 쪽지 정보를 공유하고(`index.html` 707행), `pick()`이 쪽지 전체를 레이캐스트하기 때문입니다(824–836행). 수정하지 않은 채로 넘깁니다.
- 멀리서 보면 닫힌 쪽지의 접힌 선이 복잡해 보입니다.
- 펼치는 도중 종이 뒷면이 진한 회색으로 보입니다.
