# 01. 서비스 개요

## 1. 한 줄 정의 [결정] (2026-11-14)

크리에이터의 지난 쇼츠를 폴라로이드 더미로 쌓아 둔 3D 방에서, 팬이 사진을 뒤적이며 영상을 다시 찾아내고 쪽지와 방명록으로 흔적을 남기는 크리에이터 아카이브 공간.

- 이전 정의(2026-11-10): "메시지를 보내기 전에 예상 반응을 미리 보여주는 1:1 팬 소통 서비스". AI 반응 미리보기는 남기되 서비스의 중심에서 방으로 옮겼습니다.

## 2. 전제 [결정] (2026-11-14)

| 전제 | 내용 | 근거 |
|---|---|---|
| 크리에이터 1명 | 서비스 안에 크리에이터의 방은 하나뿐입니다. 여러 크리에이터를 고르는 화면은 없습니다 | 공모전 규정: 프로젝트 하나는 크리에이터 파트너 한 명을 대상으로 함 |
| 모든 최초 접속자는 구독자 | 처음 들어온 사람은 전부 팬입니다. 로그인 화면에서 크리에이터인지 팬인지 고르지 않습니다 | 크리에이터 계정은 팀이 1~3개 만들어 대상 크리에이터에게 직접 전달 |
| 크리에이터 계정은 수동 발급 | 가입 화면으로 크리에이터가 되는 경로를 없앱니다. 크리에이터로 로그인하면 바로 크리에이터 화면(방 꾸미기)으로 갑니다 | 심사 기간에 쓸 계정 수가 적고, 크리에이터 인증 절차를 만들 필요가 없음 |

## 3. 목표 감정 [결정] (2026-11-14)

1. 오래된 사진 더미 앞에 앉아 있는 향수
2. 재밌는 쇼츠를 다시 찾아내는 즐거움
3. 팬들이 함께 쌓아 올린 공간이라는 소속감

이 셋은 기능을 고를 때의 기준입니다. 세 감정 중 어느 것도 건드리지 않는 기능은 넣지 않습니다.

## 4. 스토리: 크리에이터와 팬의 하루

크리에이터가 없어도 팬이 머물 이유가 있어야 합니다. 팬의 흔적이 있어야 크리에이터도 다시 들어옵니다. 그래서 더미, 링크, 상호작용을 캐릭터보다 먼저 만들었습니다.

| 구분 | 크리에이터 (1명) | 팬(팔로워) |
|---|---|---|

| 문제 (가설) | 지난 콘텐츠가 플랫폼 피드에 묻힘, 팬의 반응이 흩어져 있음 | 예전에 본 쇼츠를 다시 찾기 어려움, 내 흔적이 남지 않음 |
| 원하는 것 (가설) | 모아 보여줄 공간, 팬 반응의 집계 | 뒤적이는 재미, 남긴 흔적이 남아 있는 것 |

### 설계 시사점 [가설]

- 무료 참여 구간을 두어 팬 간 격차 우려를 줄입니다. 방 구경, 폴라로이드 뒤적이기, 쇼츠 재생은 로그인 없이 됩니다.
- 로그인은 흔적을 남기는 순간에만 요구합니다 (쪽지, 방명록, 채팅).
- 보내기 전 반응 예측으로 메시지 품질과 답장률을 높입니다.

### 시장 조사에서 감수한 위험 [가설]

더미형(사진을 쌓아 두고 뒤적이는) 브라우저는 애정을 얻었지만 일상 도구로는 평평한 그리드에 졌습니다. 그래서 다시 올 이유를 방에 넣었습니다: 방명록, TODAY 방문 수, 쪽지, 바뀐 방 표시.
