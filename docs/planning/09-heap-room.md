# 09. 크리에이터의 방

- 상태: [결정] (2026-11-14) 팀원이 정리한 방 구성안을 기획 문서로 편입
- 관련 문서: 01 (전제와 목표 감정), 02 (기능 범위), 08 (화면과 흐름)

서비스 안에 방은 하나입니다. 대상 크리에이터 한 명의 방이고, 들어오는 사람은 모두 팬입니다 (01 문서 §2).

## 1. 방의 구성

방의 물건마다 기능이 하나씩 붙습니다. 버튼을 화면 구석에 두는 대신 물건을 누르면 기능이 열립니다.

| 물건 | 기능 | 상태 |
|---|---|---|
| 바닥 테이블의 더미 | 지난 영상 카드를 들고, 뒤집고, 옮김 | 동작 |
| 프로젝터 | 카드를 공식 플레이어로 재생 | 동작 |
| 앨범 책장 | 주제별 앨범으로 카드 모아보기 | 동작 |
| 방명록 스탠드 | 이름과 날짜만 남기는 방명록 | 동작 |
| 벽 액자, 선반 | 크리에이터의 기념품 (이름, 날짜, 설명, 링크) | 동작 |
| 책상의 PC | 크리에이터 링크 모음 | 동작 |
| 휴대폰 | 버블로 가는 입구 | 동작 |
| 라디오 | 음악 | 동작 |
| 문 | 다른 방으로 이동, 바뀐 방에 점 표시 | 동작 |
| 크리스마스 트리 | 팬이 쪽지를 걸고 읽음 | 목업 |
| TV | 최신 업로드 | 예정 |
| 달력 | 업로드 예정일과 팬 이벤트 | 예정 |

방 전체에 더해지는 요소

- **시간대**: 방의 빛이 서울 시각을 따라 바뀝니다. 밤에는 램프가 켜지고, 어두운 방에서는 손에 든 카드가 스스로 빛납니다.
- **TODAY / TOTAL**: 싸이월드식 방문 수. 로그인한 사람만 집계합니다.
- **다녀감**: 크리에이터가 들렀다 간 흔적을 보여줍니다.

[미정]

- "문: 다른 방으로 이동"은 크리에이터가 1명이라는 전제와 맞지 않습니다. 같은 크리에이터의 방이 여러 개(주제별, 시기별)라는 뜻인지, 팬이 만든 방으로 가는 입구인지 정해야 합니다.

## 2. 디자인 결정과 이유

각 결정에는 버린 대안이 있습니다.

| 주제 | 고른 것 | 버린 것 | 이유 |
|---|---|---|---|
| 화면 형태 | 3D 방과 폴라로이드 더미 | 피드, 그리드 | 목표 감정이 향수입니다. 사진 더미를 손으로 뒤적이는 느낌은 그리드가 주지 못합니다 |
| 재생 | 공식 플레이어 (YouTube IFrame, Instagram 임베드) | 영상 다운로드, 재호스팅 | 저작권과 플랫폼 약관을 지킵니다. 프로젝터는 합법적인 재생에 자연스러움을 더합니다 |
| 출처 | 모든 카드가 원본으로 연결 | 출처 없는 이미지 | 카드 뒷면의 손글씨 메모가 이 규칙을 자연스러운 행동으로 만듭니다 |
| 가구 | Kenney CC0 로우폴리, 하나의 크기 비율 | 자체 모델링, 혼합 팩 | 라이선스 문제가 없고 모두 같은 화풍입니다. 크레딧은 편집기에 표시합니다 |
| 색 | 팔레트가 모든 가구를 다시 칠함 | 가구별 고정 색 | 크리에이터가 방송 배경색이나 브랜드 색을 방에 가져올 수 있습니다 |
| 편집기 | 방 안에서 직접 배치 (심즈 빌드 모드 방식) | 위에서 내려다보는 도면 | "편집이 쉬운지가 제품 전체를 결정한다." 보이는 그대로 놓아야 쉽습니다 |
| 가구 쌓기 | 진짜처럼 보이면 허용 | 엄격한 충돌 처리 | 약간 어설픈 겹침이 오히려 나만의 가구를 만드는 재미가 됩니다. 단, 물건의 기능을 막으면 안 됩니다 |
| 기능 배치 | 물건에 기능을 붙임, 한 슬롯에 여러 스킨 | 화면 구석의 메뉴 | 테마를 바꿔도 기능은 남습니다. 크리에이터는 물건 모양만 고릅니다 |
| 캐릭터 | 공간 먼저, 캐릭터 없이도 참여 가능 | 캐릭터 생성기 | 캐릭터는 만드는 데 오래 걸립니다. 익명으로 구경만 하고 싶은 팬도 있습니다 |
| 미니게임 | 카드 분류 게임 폐기 | 앨범 분류 점수 게임 | 정답이 제목 패턴 맞히기라 불공정했습니다. 60초 타이머는 사진을 천천히 보는 향수와 충돌했습니다 |
| 방명록 | 이름과 날짜만 | 자유 댓글 | 흔적은 남기되 관리 부담을 줄입니다 |
| AI 활용 범위 | 크리에이터가 제공한 자료만 사용 | 콘텐츠를 분석해 방을 자동 생성 | AI로 사생활을 침해하지 않습니다 |
| 공유 이미지 | 브라우저에서 캡처 → 다운로드·클립보드로 전달 | 서버 저장 | 서버에 쌓이는 파일과 비용이 없습니다 |
| 알림 | 사이트 내 알림 먼저 | 푸시, 탭 밖 토스트 | 시참에서 정했습니다 |
| 관계 | 팔로우 = 버블 방 참여, 구독 = 결제 | 별도 팔로우 기능 | 버블과 관계를 하나로 묶습니다. 구독자 전용 방은 없습니다 |

### 알고 감수한 위험

시장 조사에서 더미형 브라우저는 애정을 얻었지만 일상 도구로는 평평한 그리드에 졌습니다. 그래서 다시 올 이유를 방에 넣었습니다: 방명록, TODAY, 쪽지, 바뀐 방 표시.

## 3. 쪽지 트리 (첫 번째 프롬프트 물건)

팬에게는 미니게임처럼 재밌고, 크리에이터에게는 쓸모 있는 일이 되어야 합니다. 크리에이터가 트리를 두면 팬들이 쪽지를 써서 겁니다.

| 항목 | 내용 |
|---|---|
| 장식 | 장식이 쪽지를 품습니다. 방울, 종, 별, 하트, 선물 상자, 장갑, 눈송이, 사탕 8종이 있고 열면 쪽지가 나옵니다. 로우폴리, 색 변경 가능, 귀엽고 무난한 모양이 기준입니다 |
| 읽기 | 트리 앞의 고정 1인칭 시점입니다. 회전과 줌은 없습니다. 쪽지를 꺼내 가까이 가져와 읽고 제자리에 돌려놓습니다 |
| 쓰기 | 3D 종이 위에 손글씨 글꼴로 직접 씁니다. 종이 색과 글꼴을 고르고, 이름과 익명 중 하나를 고릅니다 |
| 자리 | 미리 정해둔 슬롯에만 겁니다. 초기 쪽지는 위에서부터 채워 트리가 일찍 꽉 차 보이게 합니다. 두 쪽지가 같은 자리에 겹치면 누르기 어렵기 때문에 자유 배치는 막았습니다 |
| 답장 | 크리에이터의 답장은 쪽지 안에 접힌 두 번째 종이입니다. 모두가 볼 수 있습니다 |
| 개수 | 한 사람이 여러 장을 남길 수 있습니다 |

- 쪽지를 거는 데는 로그인이 필요합니다. 읽기는 로그인 없이 됩니다 (08 문서 §7-1).
- 최초 접속자가 로그인한 뒤 "상호작용만 한다"를 고르면 쪽지 안내 팝업을 띄우고 트리 오브제를 하이라이트합니다.

## 4. 팬 작품 (보류 중)

팬아트, 사진, 스크린샷 링크를 더미에 올리는 기능입니다. 시장 조사에서 어느 서비스에도 없던 부분입니다. 크리에이터의 쇼츠가 바닥에 깔리고, 팬 작품이 그 위에 떨어지는 구조입니다.

1. 기본 AI·안전 필터를 거칩니다.
2. 커뮤니티가 투표합니다. 기준을 넘으면 더미 맨 위에 떨어집니다.
3. 크리에이터는 언제든 들어낼 수 있습니다. 승인 대기열은 두지 않았습니다.

승인 대기열을 버린 이유는 크리에이터의 검토 부담입니다. YouTube의 커뮤니티 기여 기능(2020)이 검토 부담과 낮은 사용량으로 종료되었습니다.
