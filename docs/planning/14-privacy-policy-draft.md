### 2. 보유 기간과 파기

| 항목 | 보유 기간 |
|---|---|
| 회원 정보(이메일 포함), 작성한 글, 경고·차단 기록 | 가입부터 탈퇴할 때까지 |
| 규칙 위반으로 공개되지 않은 글의 원문 | 가입부터 탈퇴할 때까지 |
| 탈퇴 후 보관 정보 (이메일 확인용 값, 경고 횟수, 차단 상태) | **경고를 1회 이상 받았거나 차단된 적이 있는 이용자만**, 탈퇴 후 **90일** |

- 경고와 차단 이력이 없는 이용자가 탈퇴하면 이메일을 포함한 모든 정보를 바로 지웁니다.
- 90일이 지난 탈퇴 후 보관 정보는 매일 자동으로 지웁니다.
- 90일 안에 같은 이메일로 다시 가입하면 이전 경고 횟수와 차단 상태가 새 계정에 이어집니다.
- 전자 파일은 복구할 수 없는 방법으로 지웁니다.
- 법령에 따라 보관해야 하는 정보가 있으면 그 법령이 정한 기간 동안 따로 보관합니다. [확인: 해당 여부]

### 3. 자동화된 판정과 제재

서비스는 구독자가 쓴 채팅, 쪽지, 방명록 이름을 **공개하기 전에** 자동으로 확인합니다. 크리에이터와 관리자가 쓴 글은 확인하지 않습니다.

| 단계 | 내용 |
|---|---|
| 확인 방법 | ① 금지어 목록과 문장 패턴(서버 안에서만 확인) ② 외부 판정 서비스(OpenAI Moderation API) |
| 위반이면 | 글을 공개하지 않고 작성자에게 안내합니다. 경고 1회가 쌓입니다 |
| 연락처 공유 | 전화번호, 이메일, 메신저·SNS 아이디를 공유하는 글은 공개하지 않습니다. 처음에는 안내만 하고, 두 번째부터 경고가 쌓입니다 |
| 자해 관련 글 | 공개하지 않고 크리에이터와 관리자가 확인합니다. 경고는 쌓이지 않습니다 |
| 신고 | 크리에이터나 관리자가 글을 신고하면 그 글은 "커뮤니티 정책 위반으로 삭제되었습니다"로 바뀌고 경고 1회가 쌓입니다 |
| 자동 차단 | 경고가 3회 이상이 되면 사람이 확인하기 전에 채팅·쪽지·방명록 쓰기가 자동으로 막힙니다. 로그인과 읽기 등 다른 기능은 그대로 쓸 수 있습니다 |
| 사람 검토 | 자동 차단은 크리에이터 또는 관리자가 검토해 유지하거나 해지합니다. 해지해도 경고 횟수는 줄지 않습니다 |
| 재검토 요청 | 차단된 이용자는 글쓰기 화면의 "재검토 요청" 버튼으로 다시 봐 달라고 요청할 수 있습니다 |

- 판정 서비스가 응답하지 않거나 오류가 나면 글은 공개됩니다.
- 자동화된 결정에 대해 이용자가 설명을 요구하거나 거부할 수 있는 권리가 있는지, 그 절차를 어떻게 안내할지 확인이 필요합니다. [확인: 국내 자동화된 결정 관련 규정, GDPR]

- 비밀번호는 원래 값을 알 수 없게 바꿔 저장합니다.
