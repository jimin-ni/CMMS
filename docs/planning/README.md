## 현재 상태 (2026-11-14)

전제 (2026-11-14 변경, 01 문서 §2)

- [결정] 서비스 안에 크리에이터의 방은 하나뿐. 대상 크리에이터 1명
- [결정] 모든 최초 접속자는 구독자(팬). 크리에이터 계정은 팀이 1~3개 만들어 직접 전달
- [결정] 서비스 정의: 쇼츠를 폴라로이드로 쌓아 둔 3D 아카이브 방. AI 반응 미리보기는 채팅 안의 기능으로 남김
- [결정] 목표 감정 3가지: 향수 / 다시 찾아내는 즐거움 / 함께 쌓은 공간이라는 소속감
- [결정] 과금은 "나만의 방을 갖는 것"에 검. 크리에이터 방 안의 상호작용은 무료

기능

- [결정] 채팅은 크리에이터와 팬 사이 하나뿐. 채팅에는 로그인이 필요함
- [결정] 제거: 크리에이터 톡, 크리에이터 프로필 사진, 회원가입의 역할 선택, 크리에이터 인증 절차 (02 문서 1-1절)
- [결정] 방 구경, 폴라로이드 뒤적이기, 쇼츠 재생, 쪽지·방명록 읽기는 로그인 없이 가능
- [결정] 최초 접속 흐름: 설명 → 방 → 조작 안내 → 인터랙션 유도와 내비게이션 바 → 로그인 → 분기 (08 문서 §7)
- [결정] 카드 분류 미니게임은 폐기 (09 문서 §2)
- [결정] 사용자 역할 3종은 그대로: 구독자, 크리에이터, 관리자

기술

- [결정] 팀 2명, Next.js 16 사용. 사용 버전은 03 문서 1-1절
- [결정] 인증: Better Auth (MIT)
- [결정] 데이터베이스: 관계형 DB, PostgreSQL (07 문서). Render 공유 DB를 팀이 함께 씀
- [결정] DB 접근: Drizzle ORM (#17)
- [결정] AI 반응 미리보기: TypeSafe AI Jev가 얼굴 이모지 1개를 고름
- [결정] 실시간 전달: 지금은 5초 폴링, 브랜치를 합칠 때 SSE + PostgreSQL LISTEN/NOTIFY로 바꿈 (03 문서 2절, #19)
- [결정] 브랜치 운영: 기획 변경은 `jimins-claude/plan-docs`, 개발 작업은 개발용 브랜치를 따로 만든다
- [사실] main에 인증·역할, 버블 대화방, AI 반응 미리보기, 힙 미니룸(`0007`)이 들어감. 진행 상황과 남은 작업은 04 문서 2절

미정

- [미정] 대상 크리에이터 (후보 5명 중 미정)
- [미정] 나만의 방 가격과 과금 방식, 제출본에서 모의 결제까지 만들지
- [미정] 쓰지 않게 된 DB 테이블(`creator_chats`, `creator_avatars`) 정리 여부 (03 문서 3절)
- [미정] 팬 작품 투표 기능의 구현 여부 (09 문서 §4)
- [미정] 실시간 전달의 배포 환경 확인 (프록시 버퍼링, 연결 유지, 연결 수 한도). 배포 뒤 진행 (#19)
