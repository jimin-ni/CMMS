# 11. 디자인 시안 v2 (Chipotle 팔레트 반영)

- 상태: [사실] 2026-11-18 `jimins-claude/feature-brand-design` 브랜치에 시안으로 적용. main 반영 여부는 [미정]
- 기준 자료: Chipotle DESIGN.md (Google Labs DESIGN.md 형식, shadcn.io 배포본). 색, 글꼴, 모서리, 간격, 컴포넌트 규칙만 가져오고 Chipotle 이름, 로고, 사진은 쓰지 않음
- 관련 문서: 08 (v1, 2026-11-13 화면 기록), 09 (방 구성), 04 (결정 로그)

08 문서는 v1 화면(연회색 바탕, 갈색 포인트, `system-ui`)을 적은 기록입니다. 이 문서는 그 위에 얹은 v2 시안을 적습니다. v1 팔레트(`key-*`, `talk-*`)는 `globals.css`에 그대로 남아 있어 되돌릴 수 있습니다.

## 1. 원칙

- [결정] 글자와 테두리는 진한 갈색 `ink`(#451400) 한 색이 맡습니다. 제목 색, 본문 색, 구분선 색을 따로 두지 않습니다.
- [결정] 모서리는 4px가 기본입니다. 12px는 큰 판(방의 패널)에만 씁니다. 알약 모양(999px)은 쓰지 않습니다. 동그라미가 뜻을 갖는 것(새 소식 점, 고르기 동그라미, 아바타)만 둥글게 둡니다.
- [결정] 그림자 대신 1px 테두리로 칸을 나눕니다. 고르기 칸과 숫자 칸에만 아주 옅은 후광(`0 0 40px rgba(0,0,0,0.06)`)을 둡니다.
- [결정] 제목은 대문자이고 굵기 500입니다. 위계는 굵기보다 크기로 줍니다.
- [결정] 간격의 기준은 20px입니다(칸 사이, 칸 안 여백, 화면 가장자리).
- [결정] 강조색 두 개는 아껴 씁니다. 금색(`brand-gold`)은 아직 쓰는 곳이 없습니다. 빨강(`rewards-red`)은 마이페이지 결제 카드 자리에만 씁니다.
- [결정] 종이 질감 판, 테이프, O링 수첩, 책장 넘김은 v1 그대로 둡니다. 그 안쪽만 v2 규칙을 따릅니다.

## 2. 색 토큰

`src/app/globals.css`의 `@theme`에 있습니다. Tailwind 클래스(`bg-ink`, `text-ash`, `border-hairline` 등)와 CSS 변수(`var(--color-ink)`)로 함께 씁니다.

| 토큰 | HEX | 쓰임 |
|---|---|---|
| `ink` | #451400 | 글자, 1px 테두리, 주 단추 바탕, 고른 칸 바탕, 내 말풍선 |
| `ink-soft` | #6b321b | 주 단추를 올렸을 때 |
| `ash` | #786259 | 보조 글자(설명, 시각, 칸 이름), 입력 칸 테두리, 이름표 |
| `hairline` | #d4cbc7 | 칸 안의 줄 나눔, 흰 카드 테두리, 상대 말풍선 테두리 |
| `cream` | #f2f2f2 | 빈 칸, 대화방 메시지 영역, 단추를 올렸을 때 |
| `brand-gold`, `brand-gold-deep` | #b68207, #976500 | 쓰지 않음 (한 화면에 한 곳만 쓸 자리로 남겨 둠) |
| `rewards-red`, `rewards-red-deep` | #ad2118, #9c1f16 | 마이페이지 결제 카드 자리 |
| 흰색 | #ffffff | 페이지 바탕, 카드, 입력 칸, 헤더 |

- [사실] 오류 문구는 v1의 Tailwind `red-700`을 그대로 씁니다. 기준 자료는 빨강을 오류에 쓰지 말라고 하지만, 오류는 눈에 띄어야 하므로 예외로 둡니다.
- [사실] 방 화면의 밤 같은 올리브 바탕(`--olive` #565344)은 그대로입니다. 3D 방과 어울리는 어두운 바탕이 필요해서입니다.

## 3. 글꼴

| 묶음 | CSS 변수 | 영문 | 한글 | 쓰임 |
|---|---|---|---|---|
| 제목 | `--font-display` | Oswald 500 대문자 (Trade Gothic LT Bold 대체) | 양진체(YANGJIN) | h1~h3, 쪽 제목, 칸 제목, 큰 숫자, 방 이름, "MEMOAMO" |
| 본문 | `--font-text` | Nunito | Pretendard Variable | 본문, 단추, 링크, 입력 칸 |

- [사실] 글꼴 파일과 설정은 `src/app/fonts/brand.ts`에 있고, 루트 레이아웃의 `<html>`에 변수를 붙입니다. Oswald와 Nunito는 `next/font/google`, 양진체는 `src/app/fonts/Yangjin.woff2`(원본 otf 1.6MB를 woff2 403KB로 바꿈)입니다.
- [사실] 영문 글꼴에는 한글 글자가 없으므로, 한 목록에 영문 글꼴을 먼저 두면 한글은 자동으로 뒤 글꼴로 그려집니다. 브라우저에서 "언어"는 YANGJIN, "SETTING"은 Oswald로 그려지는 것을 확인했습니다.
- [사실] `globals.css`의 `@layer base`가 h1~h3에 제목 글꼴, 굵기 500, 대문자를 줍니다. 레이어 안이라 화면별 CSS와 Tailwind 클래스가 이깁니다.

| 단계 | 크기 / 굵기 / 줄 높이 | 예 |
|---|---|---|
| 큰 제목 | 48px / 500 / 1.0~1.2 | 첫 화면 "MEMOAMO"(최대 104px), Ready to Start? |
| 가구 설명 제목 | 32~48px / 500 / 1.2 | 온보딩 가구 설명 |
| 페이지 제목 | 32px / 500 / 1.2 | 로그인, 회원가입, 미니홈 |
| 칸 제목 | 24px / 500 / 1.2 | 안내 팝업 제목, 수첩 칸 제목 |
| 본문 | 16~18px / 400 / 1.5 | 가구 설명, 안내 팝업 |
| 단추 | 13~16px / 700 대문자 | 주 단추, 보조 단추 |
| 링크, 메타 | 13~14px / 600 | 내비게이션, 방 정보 줄 |
| 작은 글 | 12px / 700 대문자 | 칸 이름, 쪽 번호, 이름표 |

## 4. 컴포넌트

| 컴포넌트 | 모양 | 쓰는 곳 |
|---|---|---|
| 주 단추 | `ink` 바탕, 흰 글자, 1px 검은 테두리, 4px, 높이 35px(넓은 것은 40px), 700 대문자 | 로그인, 회원가입, 검색, 방 만들기, 전송, 수첩 단추 |
| 보조 단추 | 흰 바탕, `ink` 글자와 1px 테두리, 4px, 높이 35px | 로그아웃, 취소, 한 줄의 두 번째 단추 |
| 입력 칸 | 흰 바탕, 1px `ash` 테두리, 4px, 높이 40px. 고르면 2px `ink` 테두리 | 로그인 팝업, 검색 |
| 카드 | 흰 바탕, 1px `hairline` 테두리, 4px. 올리면 테두리가 `ink` | 로그인·회원가입 폼, 기능 카드, 방 카드 |

| 이름표 | 1px `ash` 테두리, 4px, 12px 700 대문자 | 역할, 기능 상태, 플랫폼 |
| 탭 | 1px `ink` 테두리, 4px. 고른 탭은 `ink` 바탕 | 버블 채팅 종류 |
| 헤더 | 흰 바탕, 높이 60px, 1px `ink` 아랫줄 | 모든 앱 화면 |
| 내비게이션 링크 | 바탕 없음, 14px 600. 올리면 2px `ink` 밑줄 | 방 위 종이 메뉴 |

## 5. 화면별 적용

| 화면 | 바꾼 것 | 그대로 둔 것 |
|---|---|---|
| 헤더 (`header.tsx`) | 흰 바탕, `ink` 아랫줄, 로고는 제목 글꼴, 가입은 주 단추 | 메뉴 구성 |
| 첫 화면·온보딩 (`onboarding-c.css`) | "MEMOAMO" 제목, 부제, 스크롤 안내, 가구 설명(제목 아래 1px 흰 줄, 제목과 본문 사이 20px), Ready to Start? 단추 | 어두운 바탕, 가구가 떨어지는 연출 |
| 방 위 글자 | "MEMOAMO"와 방 이름: 20px 여백, 40px, 줄 높이 48px, 대문자. 정보 줄은 5px 아래 13px 600 | 위치 계산 방식 |
| 방 위 종이 판 | 안내 팝업, 메뉴, 로그인 팝업의 글꼴, 입력 칸, 단추, 구분선 | 종이 질감, 테이프 |
| 방 화면 (`heap-room.css`) | 단추와 칸 4px, 패널 12px, 점선을 `hairline` 실선으로, 강조색(`--clay`)과 글자색(`--ink`)을 `ink`로, 종이색(`--paper`)을 흰색으로, 글꼴 변수 `--ui`·`--hand`를 본문·제목 묶음으로 | 올리브 바탕, 3D 장면, 카드 그림, 휴대폰 모양 |
| 설정·마이페이지 수첩 (`settings-book.css`) | 쪽 안의 제목, 칸, 단추, 목록, 소리 막대 | 종이, O링, 책장 넘김, 책상 |
| 로그인·회원가입·기능·크리에이터·미니홈·요금 | 카드, 단추, 입력 칸, 이름표, 글자색 클래스 | 화면 구성 |
| 버블 채팅 | 대화방 틀(`cream` 바탕, `ink` 테두리), 머리(흰 바탕), 내 말풍선 `ink`·흰 글자, 상대 말풍선 흰 바탕·`hairline` 테두리, 전송·참여 단추, 탭 | 대화 기능, 5초 새로고침 |

- [사실] 방 화면 엔진(`heap/engine/time.js`)은 하늘이 밝을 때 방 이름 글자를 어둡게 바꿉니다. 그 색도 `ink`(#451400)로 맞췄습니다.
- [사실] 방 화면 CSS의 강조색 `--clay`는 엔진이 방마다 `C.accent`로 덮어씁니다. 그래서 방에 따라 단추 색이 `ink`가 아닐 수 있습니다.

## 6. v1 → v2 클래스 대응

일반 페이지는 아래 대응으로 바꿨습니다. v1 토큰 정의는 지우지 않았습니다.

| v1 | v2 |
|---|---|
| `bg-key-brown`, `text-key-mist` (주 단추) | `bg-ink`, `text-white`, 1px 검은 테두리, 높이 35px, 대문자 |
| `text-key-brown`, `text-gray-900/800/700` | `text-ink` |
| `text-key-stone`, `text-gray-600/500` | `text-ash` |
| `border-key-stone/50·60` | `border-ash` |
| `border-key-stone/30`, `border-key-mist`, `divide-key-stone/20` | `border-hairline`, `divide-hairline` |
| `bg-key-mist`, `bg-key-blue/30·40`, `bg-talk-bg` | `bg-cream` |
| `bg-talk-yellow` (내 말풍선, 전송) | `bg-ink` + `text-white` |
| `rounded-full`, `rounded-2xl`, `rounded-xl`, `rounded-lg` | `rounded-sm` (4px) |
| `shadow-sm`, `hover:shadow-md` | 1px `hairline` 테두리, 올리면 `hover:border-ink` |
| `bg-orange-500` (새 소식 점) | `bg-ink` |
